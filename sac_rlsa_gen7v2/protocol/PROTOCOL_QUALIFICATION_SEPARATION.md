# Gen7 V2 Qualification Role Separation

## Frozen defect

The history runner required the package-native scikit-learn B7 comparator to reproduce the Ubuntu-reported raw logits bit-for-bit. On macOS, the package-native evaluator differed only in floating-point last bits while all per-unit losses remained inside the frozen tolerance and the final policy decision agreed. That condition made a performance comparator an unintended co-authority for scientific truth.

## Repaired protocol

### Canonical truth oracle

The scientific adjudication authority is the independent strict C++ evaluator plus Decimal-40 canonical loss. It must satisfy the frozen floating-point environment tests, exact one-thread/four-thread raw identity, the strict outward loss bound, the frozen reported-loss tolerance, decision agreement, and exact Ubuntu/macOS strict-raw and Decimal-40 digests.

### B7 comparator

B7 exists only to define the strongest deployable full-audit cost denominator. The frozen portfolio remains unchanged: independent C++ one thread, independent C++ four threads, and package-native vectorized scikit-learn. Every mode is executed. A mode is eligible only if it is bound-safe, within the frozen loss tolerance, and decision-equivalent. Strict C++ modes retain exact raw identity. Package-native scikit-learn raw-bit identity is recorded as a diagnostic but is not a canonical-truth gate.

The denominator is the fastest qualified B7 mode on each platform.
